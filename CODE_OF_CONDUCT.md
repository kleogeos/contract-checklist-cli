# Code of Conduct

This is a small, single-maintainer open-source project. The expectation is simple:

- Be respectful in issues and pull requests — disagree with ideas, not people.
- No harassment, personal attacks, or spam.
- Assume good faith; most misunderstandings are just that.

Reports or concerns can be raised by opening an issue or emailing the address in the repository owner's GitHub profile. Violations may result in comments being removed or contributors being blocked from the repository.
